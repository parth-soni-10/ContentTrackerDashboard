What the dashboard measures

Explore all-time and current-year watch history, titles and screen time, comparisons with the same months last year, most-watched platforms and genres, monthly viewing patterns, recent watches, and a searchable table filterable by year, platform, type, genre, and month. A release calendar adds upcoming films and episodes for the streaming platforms in the watchlist.

How it is built

The dashboard is a static HTML, CSS, and JavaScript application. Its watchlist is stored in Cloudflare D1 (SQLite) and read by a Cloudflare Pages Function; Chart.js renders the analytics. It is a personal viewing record, not a public streaming catalogue.
