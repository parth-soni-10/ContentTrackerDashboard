Privacy

What this site stores, where it is kept, and how to remove it

The short version

Content Tracker is a personal dashboard. It has no visitor accounts, no advertising, no analytics and no third-party tracking scripts. It stores the watchlist itself, the suggestions visitors choose to submit, a small amount of state in your own browser, and standard request data at the hosting layer.

What is stored in your browser

The application keeps a little state on your own device so a reload does not lose your place. None of it is sent anywhere as analytics.

  • localStorage: ct-theme (light or dark preference), ct-media-cache (title metadata and poster lookups, so the same title is not looked up twice), ct-imdb (resolved IMDb ids), ct-cal-filters and ct-cal-region (the release calendar's last filters), and ct-goal / ct-goal-year (a device-local fallback for the yearly watch goal).
  • sessionStorage: ct_admin_session marks an unlocked admin tab. It is cleared when the tab closes.
  • Cookie: ct_admin is set only after a successful admin sign-in. It is HttpOnly, Secure, SameSite=Strict and expires when the browser session ends. Visitors who never sign in never receive it.

Clearing site data in your browser removes all of it.

What the server stores

  • The watchlist: the titles, seasons, genres, platforms, episode counts, screentime and watch dates shown on the dashboard, held in a Cloudflare D1 database.
  • Suggestions: if you use the Submit page, the title, type, genre, platform, note and date you enter are stored in the same database and shown publicly on the Submit page. Do not put personal information in a suggestion note; it is visible to everyone.
  • Admin writes: changes made from the admin panel are stored in the watchlist with the time they were made.
  • Server logs: Cloudflare, as the host, processes standard request data - IP address, user agent, requested URL and response status - to deliver the site and protect it. The application does not write those logs to its database.

Rate limiting

Submissions are rate-limited so the suggestion list cannot be flooded. The limiter counts recent writes per connection in memory and does not store IP addresses in the database or associate them with an entry. A successful submission records only the entry fields listed above.

Third parties

  • Cloudflare hosts the site and the database.
  • TMDB supplies film and series metadata and hosts poster images; TVmaze supplies episode data and hosts poster images; Watchmode supplies streaming-release data; OMDb supplies ratings. Those lookups are made by the site's server functions, except poster images, which your browser loads from image.tmdb.org or static.tvmaze.com and which therefore see your IP address as any image request does.
  • IMDb is a link target, not an embedded service. Following a title link takes you to IMDb under IMDb's own privacy policy.

There are no advertising networks, no social widgets, no fonts loaded from a third-party CDN and no analytics pixels on any page.

Your choices

  • Clear the site's storage in your browser to remove the local state listed above.
  • Email soni.soni.parth@gmail.com to ask for a suggestion you submitted to be removed, or to correct a watchlist entry. Include the title and the date so the row can be found.
  • Because there are no accounts, there is no profile to delete: nothing is tied to your identity unless you chose to put it in a suggestion note.

The site is a personal media log rather than a service aimed at children, and it collects no information from visitors beyond what is described here. If this policy changes, the date below changes with it; there is no mailing list, so this page is the notice.
